# 前端界面说明

## 界面组织

保留项目蓝色主色和 Vue 3 技术栈，将业务入口整理为角色工作台。首页直接呈现当前任务，导航用于切换业务页面。开发技术栈介绍、英文模块标签和装饰性进度条已移出用户界面。

| 身份 | 导航入口 |
| --- | --- |
| 游客 | 配件商城、服务门店、登录 / 注册 |
| 车主 | 配件商城、服务门店、购物车与订单、预约与保养、我的账户 |
| 加盟店 | 订单核销、预约与保养、到店二维码、我的账户 |
| 管理员 | 加盟店审核、商品与库存、订单与配送、我的账户 |

通过登记二维码打开页面时，导航额外提供“扫码到店登记”。链接保留 `?checkInStore={门店ID}#check-in`。用户从登记页面登录后返回该门店的登记入口。

各模块首次打开时才加载；已打开的模块保持挂载，切换页面保留表单和分页状态。账号变化时重建工作台，购物车仍按账号分别保存。订单的“预约保养”会切换到预约页面并预选订单与门店；登记、核销、预约和保养操作继续沿用既有的数据刷新事件。

桌面使用侧边导航；宽度不超过 900px 时使用可展开菜单，640px 以下表单和列表采用单列布局。移动菜单可用 Escape 收起并返回触发按钮。页面提供跳过导航入口和可见的键盘焦点。

## 使用的设计资源与依赖

| 资源 | 用途 |
| --- | --- |
| Impeccable | 按任务型界面整理层级、间距、文案与响应式布局，沿用已有品牌色 |
| UI Skills：baseline-ui | 统一控件、状态、图标和金额展示 |
| UI Skills：fixing-accessibility | 标签、按钮名称、展开状态、焦点与原生对话框 |
| `morphicons` 1.7.1 | 使用官方 `morphicons/vue`，处理手机菜单图标的展开 / 收起变化 |
| `lucide` 1.52.0 | 导航、商品、门店和评分的统一 SVG 图标数据 |

Morphicons 是图标动画库。表单、按钮和对话框继续使用 Vue 与浏览器原生控件，公共样式定义在 `front/src/style.css`。菜单动画设置 `reduced-motion="user"`，尊重系统减少动画偏好。

公共组件：

- `UiIcon.vue`：从 Lucide 图标数据渲染 SVG，装饰图标不参与朗读。
- `DataState.vue`：加载占位、空列表和失败后的操作提示。
- `ConfirmDialog.vue`：原生 `<dialog>`，用于删除商品、清空购物车和取消预约；默认聚焦保留按钮，支持 Escape 取消和关闭后的焦点恢复。
- `PaginationControls.vue`：统一分页导航。
- `ReviewList.vue`：商品和门店评价、评分与分页。

## 交互细节

- 商品配件价与单件工时费分开显示，缺货状态直接标注；游客可从商品进入登录。
- 购物车数量在提交修改时验证整数、库存和数量上限，避免不合法输入污染合计金额。
- 商品编辑、预约、评价和保养表单提供常驻字段标签与必要的计价单位；商品库存仍可编辑，也可在列表中增减。
- 请求期间禁用重复提交，初次加载使用结构占位；加载失败与暂无数据分别提示。
- 加盟店审核使用明确的成功 / 错误状态，刷新列表保留操作结果。
- 门店二维码支持重新加载门店资料、生成登记链接和保存 PNG。
- 网络与服务错误使用中文恢复提示；业务拒绝原因仍显示后端返回的信息。

前端仍只通过 `/api` 请求后端。角色导航用于组织界面，权限、数据归属和库存事务继续由后端校验。
